# 收款码图片目录

请将您的收款码图片上传到此目录：

- `alipay.png` - 支付宝收款码图片
- `wechat.png` - 微信收款码图片

## 图片要求

- 格式：PNG 或 JPG
- 尺寸：建议 512x512 像素或更大
- 内容：清晰的收款二维码，确保可以正常扫描

## 上传步骤

1. 生成支付宝和微信收款码
2. 将收款码保存为图片
3. 重命名为 `alipay.png` 和 `wechat.png`
4. 上传到此目录

## 注意事项

- 确保收款码清晰可扫描
- 建议使用白色背景的收款码，显示效果更好
- 上传后可以通过 `/support` 页面测试显示效果
